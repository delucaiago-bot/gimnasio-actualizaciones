# Gimnasio · versiones publicadas

Aquí se publican las versiones de la app **Gimnasio** (Android). La app instalada consulta este
repositorio al abrirse y ofrece instalar la versión nueva.

## Instalar por primera vez

1. Descarga el APK de la [última versión](https://github.com/delucaiago-bot/gimnasio-actualizaciones/releases/latest).
2. Ábrelo y permite «Instalar apps de origen desconocido».
3. Las siguientes versiones se instalan desde la propia app (aviso «Nueva versión» → Actualizar).
